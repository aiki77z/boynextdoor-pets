# Dalring Reference Pack Spec

## Purpose

This document defines the correct input reference pack for hatching Dalring / 獭灵 as a 2D desktop pet that matches the intended soft mascot style.

Target style:

- not 3D
- not realistic
- not pixel art as the final finish
- not plush photo realism
- not clay render
- soft, clean, flat 2D mascot feel
- slight soft shading is allowed
- should feel like an official-style chibi mascot turned into a moving desktop pet

The main goal is likeness to Dalring first, and animation production second.

## Main Principle

Dalring should be guided by three kinds of references:

1. identity reference
2. structure reference
3. style rule reference

If we want strong likeness, the identity image must lead the pack.

## Recommended Folder Layout


## Reference Roles

### 01-identity-front.jpg

Use the clean front-facing Dalring image as the primary identity anchor.

This image is responsible for:

- exact head-to-body ratio
- overall otter silhouette
- brown upper head and body mass
- cream-white face and belly placement
- sleepy half-closed eyes
- tiny nose and simple mouth
- calm, quiet expression
- overall "this is Dalring" recognition

This is the single most important image in the pack.

If you do not have a non-pixel official-style Dalring image yet, use the clearest full-body reference you have for now, but replace it later when a cleaner mascot image is available.

### 02-structure-breakdown.jpg

Use the decomposition, face close-up, or pixel breakdown image as the structural correction reference.

This image is responsible for:

- eye shape and eyelid angle
- nose and mouth placement
- ear shape
- belly contour
- arm and foot proportions
- donut or small hat placement if relevant

This image is used to stop drift into a generic brown animal mascot.

### 03-style-notes.md

Use a text note to lock the rendering direction.

This note is responsible for:

- no 3D rendering
- no realistic fur texture
- no pixel-art conversion as the final output
- no hard plastic gloss
- no clay sculpture rendering
- allow soft simple shading only
- keep the look like a clean 2D mascot illustration with gentle volume

### 04-alt-front.jpg

Optional.

Use another front-facing Dalring image only if it supports the same silhouette and face design.

Good use:

- confirming sleepy eye expression
- confirming cream face area size
- confirming body proportion

Bad use:

- introducing different eye style
- introducing a different species feeling

### 05-face-closeup.jpg

Optional but useful.

Use a close-up reference when the generated face is close but still not right.

This image is responsible for:

- eye spacing
- eyelid droop
- muzzle balance
- nose size
- mouth shape

### 06-prop-donut.jpg

Optional.

Use only if you want the donut to become a stable recurring prop in happy, sleep, or special rows.

This image is responsible for:

- donut size
- donut color
- how the prop should read next to Dalring

## Priority Order

If we can only use two references:

1. `01-identity-front.jpg`
2. `02-structure-breakdown.jpg`

If we can use more:

3. `03-style-notes.md`
4. `04-alt-front.jpg`
5. `05-face-closeup.jpg`
6. `06-prop-donut.jpg`

## What To Avoid

Do not feed references that introduce the wrong finish:

- pixel-art versions as the only style anchor
- realistic plush toy photos
- 3D fan renders
- glossy figurine renders
- blurry screenshots
- images with exaggerated comedy faces that break the calm identity
- props bigger than the pet

## Practical Recommendation

For Dalring's first real hatch run, the minimum correct pack is:

- `01-identity-front.jpg`
- `02-structure-breakdown.jpg`
- `03-style-notes.md`

If you also have a clear face crop, add:

- `optional/05-face-closeup.jpg`

This is enough to target the right visual branch.
