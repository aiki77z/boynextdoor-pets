# boynextdoor-pets
A desktop pet application based on the BOYNEXTDOOR prototype.

## AI Pet Chat
Click the `AI` button in the pet controls to open model settings. After AI is enabled, the chat button becomes available for lightweight pet conversations.

- Users bring their own DeepSeek API key.
- Enabling AI requires an API key.
- User messages are limited to 100 characters.
- Each pet keeps only a short rolling memory of recent turns.
